# Polyanskaya_Photo

Персональное приложение фотографа для учёта фотосессий, клиентов, доходов и онлайн-записи.
Работает в браузере, ставится на iPhone как отдельное приложение (PWA), работает без интернета, хранится бесплатно на GitHub Pages.

**Что умеет**

- Журнал фотосессий: вид, клиент, длительность, стоимость, оплата (полностью / частично / не оплачено), локация, комментарий; поиск по клиенту, фильтры по периоду, виду и оплате.
- Главная: доход, количество съёмок и рабочее время за сегодня, месяц и год; быстрые действия; ближайшие съёмки.
- Статистика: доход по дням / неделям / месяцам и за любой период, круговая диаграмма видов съёмок, рабочее время, средний чек, доход за час.
- Клиенты: карточка с историей съёмок, суммой, заметками и быстрыми ссылками (звонок, Telegram, Instagram).
- Календарь: новые заявки, подтверждённые, проведённые и отменённые съёмки, свободные дни.
- Онлайн-запись для клиентов (`booking/`) и уведомление в Telegram через безопасный Cloudflare Worker.
- Раздел «Заявки»: подтвердить (заявка становится съёмкой), изменить, связаться, отменить.
- Копия данных в JSON, таблица для Excel (CSV), загрузка копии, офлайн-режим.

Все ссылки внутри проекта относительные, поэтому он работает по адресу вида `https://логин.github.io/имя-репозитория/`.
Папку `backend/` и `docs/` на GitHub можно не загружать — сайту они не нужны (но и не мешают).

## 1. Как запустить на компьютере (для проверки)

Приложению нужен обычный веб-сервер (service worker не работает с `file://`). Если установлен Python:

```
cd polyanskaya-photo
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Страница записи: `http://localhost:8000/booking/`.

## 2. Как загрузить на GitHub

1. Откройте свой репозиторий на github.com (или создайте новый: **+ → New repository**, название, например, `polyanskaya-photo`, доступ **Public**).
2. **Add file → Upload files**.
3. Перетащите **содержимое** папки `polyanskaya-photo` (файлы `index.html`, `style.css`, … и папки `js`, `booking`, `assets`, `backend`, `docs`). Файл `index.html` должен лежать в корне репозитория, а не в подпапке.
   - В браузере на компьютере папки можно перетаскивать целиком. Если папки не загружаются, распакуйте zip и перетащите всё выделенное разом.
4. Внизу нажмите **Commit changes**.

Чтобы обновить файл позже: откройте его в репозитории → значок карандаша (или **Add file → Upload files** с тем же именем) → **Commit changes**.

> После каждого обновления файлов приложения поднимайте номер в первой строке `service-worker.js`
> (`const VERSION = "pp-v1"` → `"pp-v2"`), иначе телефон может ещё какое-то время показывать старую версию.

## 3. Как включить GitHub Pages

1. В репозитории: **Settings → Pages**.
2. **Source: Deploy from a branch**, ветка **main**, папка **/ (root)** → **Save**.
3. Через 1–2 минуты вверху страницы появится адрес: `https://логин.github.io/имя-репозитория/`. Откройте его — это ваше приложение.
4. Страница для клиентов: тот же адрес + `booking/`.

## 4. Как установить на iPhone

1. Откройте адрес приложения в **Safari** (именно Safari, не Chrome).
2. Нажмите **«Поделиться»** (квадрат со стрелкой внизу) → **«На экран Домой»** → **«Добавить»**.
3. Запускайте приложение с иконки Polyanskaya_Photo — оно открывается без адресной строки, как обычное.

**Важно про данные.** На iPhone Safari и установленное приложение хранят данные раздельно.
Поэтому сначала установите приложение, а потом начинайте вносить съёмки в нём.
Если уже вносили данные в Safari: в Safari **Настройки → Сохранить копию**, затем в установленном приложении **Настройки → Загрузить копию**.

## 5. Telegram-уведомления и онлайн-запись

Нужны бесплатные аккаунты Telegram и Cloudflare. Полная пошаговая инструкция: **[docs/TELEGRAM.md](docs/TELEGRAM.md)**: BotFather, токен, Chat ID, куда вписать токен, деплой Worker, подключение к приложению.

Кратко: бот создаётся в @BotFather → Worker создаётся в Cloudflare (код из `backend/telegram-worker.js`) → токен и Chat ID вписываются в **секреты Cloudflare** → адрес Worker вписывается в `config.js` → ключ доступа вводится в Настройках приложения.

Токен бота **нельзя** вписывать в `config.js` или любой файл проекта: репозиторий публичный.

Пока Worker не подключён, приложение полностью работает: заявки можно добавлять вручную («Новая запись»), а страница записи покажет клиенту, что онлайн-запись недоступна.
Проверить саму форму без сервера можно по адресу `booking/?test=1`: заявка сохранится на устройстве и появится в приложении.

## 6. Резервное копирование

Данные хранятся только на вашем устройстве, поэтому копии важны.

- **Настройки → Сохранить копию (JSON)** — полная копия всех данных. На iPhone откроется меню «Поделиться»: выберите **«Сохранить в Файлы»** (iCloud Drive) — копия будет в вашем облаке.
- **Настройки → Загрузить копию** — восстановление из такого файла (текущие данные заменяются; сразу после загрузки можно нажать «Отменить»).
- **Таблица съёмок для Excel (CSV)** и **Список клиентов (CSV)** — открываются в Excel и Numbers (кодировка и разделитель настроены под русскую версию).
- Делайте копию раз в неделю и перед очисткой данных Safari или удалением приложения. Удаление иконки приложения с iPhone удаляет и его данные.
- Приложение само хранит предыдущую версию данных на случай сбоя записи, но это не замена копии.

## 7. Как считаются цифры

- **Доход** — реально полученные деньги: «Оплачено» = вся стоимость, «Частично» = сумма «Получено», «Не оплачено» = 0.
- В статистику и на главную попадают **проведённые** съёмки и съёмки **на сегодня**. Будущие и отменённые не считаются. Съёмка с прошедшей датой автоматически становится «Проведена».
- **Средний чек** = доход ÷ количество съёмок. **Доход за час** = доход ÷ общее рабочее время в часах.
- **Самый загруженный день** — день с наибольшим числом съёмок (при равенстве — с большим временем).
- Заявка после «Подтвердить» открывает форму съёмки с данными клиента; после сохранения становится запланированной фотосессией и появляется в календаре. Если эту съёмку удалить, заявка вернётся в «Новые».

## 8. Облачная база (Supabase / Firebase) на будущее

Весь код читает и пишет данные только через `PP.store`, а тот — через один объект `PP.storageAdapter` в начале `js/store.js` (методы `load()` и `save(db)`).
Чтобы перейти на облачную базу, замените этот адаптер на свой, который читает/пишет документ с данными в Supabase или Firebase. Остальные файлы менять не нужно.
Сейчас адаптер работает с `localStorage` (с автоматической резервной копией предыдущей версии).

Сейчас облачной синхронизации **нет**: данные живут на одном устройстве. Между устройствами переносите копию вручную.

## 9. Что проверено

Автоматически проверено в эмуляции iPhone 13, iPhone SE (320 px), iPad и компьютера (Chromium): добавление, редактирование, удаление с отменой, фильтры и поиск, расчёты статистики, клиенты, подтверждение заявок, страница записи, календарь, экспорт и импорт, офлайн-режим, отсутствие горизонтальной прокрутки. Cloudflare Worker проверен 31 тестом на макетах Telegram и KV (проверка данных, защита от спама, права доступа, экранирование).

**Не проверено** на реальном iPhone и с реальными Cloudflare и Telegram — у меня нет доступа к вашим аккаунтам. После настройки пройдите «Шаг 10» из `docs/TELEGRAM.md`: он займёт пять минут.
